# My Portfolio

A personal developer portfolio built with React, TypeScript, Vite and Tailwind CSS.

## About

This repository contains my personal portfolio website, designed to showcase
my software development experience, technical skills, and projects.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS

## Features

- Responsive design
- Project showcase
- Skills and technologies section
- Project details
- Contact section
- Animations and interactive UI
- Responsive navigation
